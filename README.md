# Yun-Ho Han Personal Homepage

This repository is prepared for GitHub Pages.

## Structure

```text
YunhoHan.github.io/
├── index.html
├── cv.html
├── assets/
│   ├── style.css
│   ├── script.js
│   └── cv.css
├── documents/
│   └── Yunho_Han_CV_EN_v1_0.pdf
└── README.md
```

## Deployment

1. Create a GitHub repository named `YunhoHan.github.io`.
2. Upload or push all files in this folder to the repository.
3. Go to **Settings → Pages**.
4. Set source to **Deploy from a branch**.
5. Select branch `main` and folder `/root`.
6. Open `https://yunhohan.github.io`.

## Updating the CV

Replace:

```text
documents/Yunho_Han_CV_EN_v1_0.pdf
```

with a new PDF using the same filename, or update the links in `index.html`.
